## 3. 정하셔야 할 것

### 3-1. 영상회 — 프레임 단위 타임코드

설계 문서에 적어 둔 `HH:MM:SS` 구간 지정은 **아직 안 만들었습니다.** 이유를 다시 적습니다:

우리 화면은 영상과 동기화되지 않습니다. 상영 시작을 누른 시각을 기준으로 세는 방식이라
**사람이 버튼을 누르는 오차(±0.5초)를 못 넘습니다.** 프레임 단위 정밀도를 적어 넣으면 화면은
정확해 보이는데 실제로는 그만큼 안 맞아요 — 그래서 "몇 초마다 바뀐다" 만 먼저 만들었습니다.

필요하시면 **상영 시작 버튼 + 경과 시간 표시** 정도로 붙일 수 있습니다. 하실까요?

### 3-2. 포토카드 이미지의 권리 (그대로)

아이돌 사진을 뽑아서 **저장까지** 하게 되는데, 초상권·저작권이 전부 남의 것입니다.
편집기 경고·주최자 안내·슬롯 삭제 시 완전 삭제까지는 넣어 뒀지만 **법적 판단은 제 범위 밖**입니다.

  창과 양식 양쪽에 적었습니다. (고르게 두면 '일반' 을 고르고 3일 뒤 검수를 원하시는 일이 생깁니다.)
- 방문자가 관리자 페이지에서 직접 넣는 것(경품·문항·카드·암호)은 **칸을 만들지 않고 `※` 안내**로

| 투표 | 색·문구·결과 표시 방식 | 설문·선택지·공개·마감 |
| **영상회 응원** | 말풍선 팔레트·먹색/종이색, 색·문구 | **개수·비율·간격·이름 표시·입력 수·글자 수·마감** |

기준은 하나입니다: **행사 중에 바뀌는 값이면 주최자, 배포 전에 정하면 편집기.**
예외는 **이미지 업로드는 무조건 편집기** — Storage 쓰기가 담당자 계정으로만 잠겨 있습니다.
