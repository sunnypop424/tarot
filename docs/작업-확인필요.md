## 2. 제가 임의로 정한 것 (뒤집으셔도 됩니다)

### 2-1. 소원나무 등불 배치 — 시안 좌표를 "규칙"으로 바꿨습니다

시안(`소원 나무 방문자.dc.html`)은 등불 좌표를 손으로 찍어뒀는데, 그 좌표는 **소원이 딱 7개일 때만** 맞습니다. 실제로는 3개일 수도 300개일 수도 있어서, 시안의 *성질*을 규칙으로 옮겼습니다:

- 가로·세로를 등불마다 따로 뽑고, **겹치면 24번까지 다시 뽑습니다** (`src/wish/WishApp.tsx` 의 `scatter`)
- **살짝 겹치는 건 허용**했습니다 — 시안 모바일도 2·3번 등불이 16px 겹칩니다. 안 겹치게 하면 사이가 훤해져 "칸마다 놓인" 것처럼 보입니다
- 겹칠 땐 **아래 등불이 위로** 옵니다 (나무는 가까운 게 아래)
- 크기는 92~126px 사이에서 **연속으로** 흩었습니다. 시안은 두 종류지만 글 길이에 따라 높이가 또 달라져 실제로는 다 달라 보입니다
- 값은 전부 메시지 id 에서 뽑아서 **새로고침해도 자리가 안 바뀌고**, 소원이 하나 늘어도 남의 등불이 안 움직입니다

### 2-2. 빛번짐을 시안보다 옅게 했습니다

시안은 `opacity 0.4 → 0.5~0.85` 인데, 시안은 등불이 일곱 개뿐이라 각각 따로 보입니다. 실제로 소원이 빽빽해지면 **halo 가 서로 뭉쳐 배경이 하얗게 떴습니다**(실제로 그랬습니다). `0.3 → 0.34~0.62` 로 낮췄습니다.
→ **더 밝은 게 좋으시면 `src/wish/Wish.module.css` 의 `.glow` 와 `@keyframes wtGlow` 숫자만 올리시면 됩니다.**

### 2-3. 한 페이지 = 한 화면

소원이 쌓여도 스크롤이 끝없이 길어지지 않게, **가지에 실제로 들어가는 만큼만** 걸고 나머지는 다음 페이지로 넘깁니다. 기기 폭·높이를 실측해서 정하므로 기기마다 개수가 다릅니다 (iPhone SE 4개 / iPhone 12 6개 / iPad 18개).
**롤링페이퍼에도 같은 걸 넣었습니다** (열 수 × 6장).

### 2-4. 줄이 길수록 좌우 여백을 더 줍니다

흔들림이 줄 맨 위를 축으로 도는 거라 **줄이 길수록 아래쪽이 크게 움직입니다**(drop 500px → 약 19px). 여백을 고정했더니 iPhone 15 Pro Max·iPad mini 에서 **긴 줄 등불만 화면 밖으로 잘렸습니다.** 줄 길이에 비례해 안쪽으로 당기도록 고쳤습니다. 시안은 줄이 짧아(≤268px) 드러나지 않던 문제입니다.

### 2-5. 소원나무 헤더를 롤링페이퍼와 같은 규칙으로

말씀대로 맞췄습니다 — 로고가 있으면 **제목을 대신**하고(옆 타일 아님), `logoAlign`·`logoMarginTop` 으로 정렬·위 여백을 고릅니다. 시안은 로고 타일이 제목 옆에 붙는 형태였는데 그쪽을 버렸습니다.

### 2-6. 등불 기본색을 연한 한지 톤으로 바꿨습니다

원래 제가 넣었던 진한 색(주황·자주)은 **등불 안 글씨가 안 읽혔습니다.** 시안의 연한 톤(`#efe8cd` 등)으로 교체했고, 글자색도 어둡게 맞췄습니다. 이 짝을 깨면 소원이 안 읽히니 색을 바꾸실 때 같이 봐주세요.

### 2-7. 촬영 화면은 슬롯 색을 안 씁니다 (포토존)

카메라 화면·실패 화면만 **고정 다크**입니다. 카메라 UI 는 어느 이벤트든 검고, 프리뷰가 주인공이라 주변이 밝으면 눈이 그리로 갑니다. 시안도 그렇습니다.

## 5. 여쭤볼 것

### Q1. 포토카드 "럭드와 비슷하게" 의 범위

말씀하신 대로 시안을 참고하되 럭드에 맞추려는데, **어디까지 맞출지**가 갈립니다:

- **(가) 운영 흐름만** — 스태프 기기·리허설·마감·묶음뽑기 같은 운영 개념을 럭드와 똑같이. 화면은 시안(부채꼴 덱·카드 뒤집기)
- **(나) 화면까지** — 럭드처럼 타일 그리드 + 스크래치로. 시안의 덱 연출은 버림

저는 **(가)** 로 갈 생각입니다 — 포토카드는 "카드를 뒤집는 순간"이 서비스의 전부라서요. 다르게 원하시면 말씀해 주세요.

### Q2. 소원나무 배경 이미지를 올리면 별·가지를 지울까요?

지금은 배경 이미지를 올리면 **CSS 밤하늘·별·가지를 전부 숨깁니다**(이미지가 이미 하늘이라고 보고). 그런데 이미지가 나무만 그린 거라면 별이 사라져 허전할 수 있습니다.
→ 편집기에 "별 보이기" 체크박스를 따로 둘까요?

### Q3. 페이지 나누기를 롤링페이퍼에도 넣었는데, 기존 이벤트가 있나요?

이미 운영 중인 롤페 슬롯이 있으면 **손님이 보던 화면이 바뀝니다**(전부 스크롤 → 페이지). 지금 도는 이벤트가 있으면 알려주세요 — 롤페만 되돌리거나 개수 기준을 높이겠습니다(예: 40장 넘을 때만 페이지).

### Q4. 모의고사 서술형 — 정말 빼도 될까요?

앞서 "서술형 자체를 뺀다"로 정하셨는데, 원문엔 세 유형이 다 있었습니다. 객관식·주관식만으로 만들 예정이고 **나중에 붙이려면 문항 유형만 늘리면 되게** 열어두겠습니다. 그대로 진행하면 됩니다.

### Q5. 액세스 토큰 폐기 시점

`SUPABASE_ACCESS_TOKEN` 은 계정 전체 권한입니다. 작업이 다 끝나면 대시보드에서 폐기하시는 걸 권합니다. 제가 쓴 건 `supabase/migrations/` 안의 SQL 실행뿐이고, 적용 이력은 `public._applied_migrations` 테이블에 남습니다.
