# 새 서비스 설계 메모 — 영상회 라이브 응원 (`cheer`)

사장님이 주신 아이디어를 잃지 않게 먼저 적어 둡니다. **아직 안 만들었습니다** (작업 목록 #24).
아래는 제가 정리한 설계와, 만들기 전에 정하셔야 할 것들입니다.

## 무엇인가

아이돌 **영상회**(팬들이 모여 영상을 같이 보는 자리)에서 쓰는 응원 오버레이입니다.

```
영상회 입구 QR  →  사이트 입장  →  한마디 입력(이름 선택)  →  서버 저장
                                                        ↓
                    상영 화면 두 가지 중 하나로 스크린에 뜬다
                      ① 영상 테두리에 말풍선·스티커로 프레임처럼
                      ② 상영 끝나고 엔딩크레딧처럼 흐르기
```

## 데이터는 **롤링페이퍼를 그대로 쓴다**

한마디 = 닉네임 + 본문 + 숨김 여부. **롤페(`rolling_messages`)와 모양이 완전히 같습니다.**
소원나무(`wish`)가 이미 그렇게 하고 있어요 — 테이블을 새로 만들면 검수 화면·RLS·verify 를
한 벌 더 만들게 되고, 한쪽만 고치는 날이 옵니다.

그래서 새로 만드는 건 **화면과 설정뿐**입니다:
- `slots.cheer` jsonb 한 칸 (겉모습)
- 상영 화면 두 개 + 방문자 입력 화면
- 주최자 검수는 **롤페 검수 화면을 그대로** 씁니다

## 화면 넷

| 화면 | 주소 | 누가 |
|---|---|---|
| 한마디 입력 | `/{slug}` | 방문자 (폰) |
| **오버레이** | `/{slug}/overlay` | 상영 노트북 — **배경이 투명**합니다 |
| 엔딩크레딧 | `/{slug}/credits` | 상영 노트북 (전체화면) |
| 검수·상영 제어 | `/{slug}/admin` | 주최자 |

**오버레이 배경을 투명하게 두는 게 핵심**입니다. 그래야 OBS·프리즘 같은 방송 도구에서
'브라우저 소스'로 얹어 영상 위에 그대로 올릴 수 있어요. 영상 파일을 우리가 다루지 않아도 되고,
프로젝터로 쏠 때도 창을 겹치기만 하면 됩니다.

## 상영 규칙 (사장님이 말씀하신 부분)

- **N초마다 교체 — 다만 한꺼번에 갈아치우지 않습니다.**
  6초로 정하면 6초마다 **전부** 바뀌는 게 아니라, 말풍선마다 자기 시계를 가집니다:
  기준 6초 ± 무작위(예: 4~8초)로 하나씩 **슉 하고 나타났다 사라집니다.**
  전체가 동시에 깜빡이면 화면이 번쩍여서 영상이 안 보이고, 하나씩 어긋나면
  "사람들이 계속 말을 걸고 있는" 느낌이 납니다.
- **자리도 무작위** — 정해진 슬롯에 순서대로 꽂는 게 아니라 화면 가장자리 안에서 임의 위치.
  단 **서로 많이 겹치지 않게** 잡습니다(새 자리를 고를 때 이미 떠 있는 말풍선과의 거리를 보고,
  몇 번 튕기면 그 순번은 건너뜁니다 — 자리를 억지로 만들면 결국 겹칩니다).
  가운데는 늘 비워 둡니다: 거기 영상이 있습니다.
- **모양도 무작위** — 아래 '말풍선 스타일' 에서 하나를 뽑아 씌웁니다.
  색은 **편집기에서 슬롯이 정한 팔레트 안에서만** 섞습니다 (아무 색이나 나오면 행사 색이 무너집니다).

## 말풍선 스타일 — 예능 자막바 결 (보내주신 이미지 기준)

받은 참고 이미지는 전부 **예능 자막바** 계열입니다. 공통 문법이 뚜렷해서 그대로 규칙으로 씁니다:

- **굵은 검정 외곽선**(3~4px)과 **아래로 눌린 그림자**(offset 3~4px, 번짐 없음) — 종이 스티커처럼 떠 보입니다
- **이름 칩 + 본문 바** 두 칸 구조 (`김클립 | 저는 음식 냄새에 예민해요`)
- 색은 **2~3색**만. 진한 색 칩 + 흰 본문이 기본, 반대로 진한 본문 + 흰 글자도 씀
- 살짝 **기울임**(-3°~3°)과 **꼬리**(왼/오/아래)

만들 변형 여섯 (전부 CSS 로 그립니다 — 이미지 없이):

| 변형 | 생김새 | 언제 |
|---|---|---|
| `chipBar` | 이름 칩 + 흰 본문 바, 둥근 알약 | 이름이 있을 때 기본 |
| `solidBar` | 색으로 꽉 찬 바 + 흰 글자 | 이름이 없을 때 |
| `bubble` | 둥근 말풍선 + 꼬리(방향 랜덤) | 짧은 한마디 |
| `banner` | 양 끝이 제비꼬리인 리본/현수막 | 아주 짧은 한마디("최고!") |
| `burst` | 별 모양 폭발 배지 | 감탄사 (10자 이하일 때만) |
| `plaque` | 모서리를 깎은 명패, 위에 작은 이름표 | 이름 + 짧은 한마디 |

**고르는 규칙:** 글자 길이와 이름 유무가 후보를 좁히고, 그 안에서 무작위로 뽑습니다.
20자짜리를 `burst` 에 넣으면 읽을 수 없으니까요. 방금 쓴 변형은 다음 두 번은 피합니다
(연속으로 같은 모양이 뜨면 무작위가 아니라 고장으로 보입니다).

**등장 연출:** 아래에서 살짝 튀어 오르며(translateY + scale 0.9→1) 0.25초에 들어오고,
사라질 땐 0.2초에 흐려집니다. `prefers-reduced-motion` 이면 그냥 켜고 끕니다.
- **구간 지정** — `HH:MM:SS` 로 시작·끝을 적으면 그 구간 동안만 프레임이 뜹니다.
  프레임 단위까지 필요하시면 `HH:MM:SS:FF` + fps(24/30/60)로 받습니다.
  다만 **우리 화면은 영상과 동기화되지 않습니다** — 상영 시작 시각을 눌러 기준을 맞추는 방식이라,
  프레임 단위 정밀도는 사람이 버튼을 누르는 오차(±0.5초)를 못 넘습니다. 그래도 넣을지 정해 주세요.
- **빠지는 한마디가 없게** — 한 바퀴를 다 돌기 전에는 같은 걸 다시 안 띄우고,
  다 돌았는데 자리가 남으면 그때부터 중복으로 채웁니다 (말씀하신 그대로).
  자리 수보다 한마디가 적으면 처음부터 중복이 되고요.

## 정해진 것 (사장님 결정)

**운영값은 전부 주최자 화면에서 정합니다.** 겉모습(색·팔레트·폰트·배경)만 편집기(최고관리자)입니다 —
다른 서비스와 같은 경계예요: **행사 중에 바뀌는 값이면 주최자.**

| 항목 | 어디서 | 범위 | 화면에 적을 가이드 |
|---|---|---|---|
| 한 화면에 몇 개 | 주최자 | 1~10개 (기본 6) | "6~8개가 가장 보기 좋아요. 10개면 영상이 가려질 수 있어요" |
| 영상 비율 | 주최자 | 16:9 · 4:3 · 21:9 · 직접입력 | "가운데를 이 비율만큼 비워 둡니다 — 영상이 뜨는 자리예요" |
| 교체 간격 | 주최자 | 3~15초 (기본 6) | "말풍선마다 이 값의 ±30% 로 흩어져서 하나씩 바뀝니다" |
| 이름 표시 | 주최자 | 켬/끔 (기본 켬) | "끄면 한마디만 떠요. 익명 행사에 쓰세요" |
| 1인 입력 수 | 주최자 | 1~10개 (기본 3) | "3개면 대부분 만족하고, 10개면 한 사람 글이 화면을 채웁니다" |
| 글자 수 | 주최자 | 10~60자 (기본 40) | "40자가 말풍선에 예쁘게 들어가요. 60자는 글씨가 작아집니다" |

**검수는 롤링페이퍼·소원나무와 같습니다** — 다 뜨고, 주최자가 목록에서 숨깁니다(사후).
같은 테이블·같은 검수 화면을 쓰니 배우는 것도 하나입니다.
다만 영상회는 큰 화면에 뜨는 자리라, 검수 화면을 **상영 중에도 열어두시라고** 안내에 적습니다
(숨기면 다음 교체부터 사라집니다).

**가이드는 설정 옆에 그대로 적습니다.** 숫자만 있는 칸은 "몇 개가 맞는지" 를 아무도 모릅니다 —
이 표의 오른쪽 열이 그대로 화면 힌트가 됩니다.

## 만들 때 지킬 것 (이 레포 규약)

- `SERVICES` 에 한 줄 추가 → `Record<ServiceId, …>` 소비처 여섯 곳이 컴파일 에러로 터집니다.
  그 여섯 곳(앱·관리 라우트·메뉴·미리보기 화면·대시보드·점검)을 다 채우면 서비스가 붙습니다.
- 오버레이 화면은 **슬롯 테마 색**을 씁니다 (손님이 같이 보는 화면이라 관리 도구 라이트가 아닙니다).
- 이미지(스티커·프레임 PNG)는 전부 `background-image` 입니다.
- 마이그레이션이 프론트보다 **먼저** 나갑니다 (`slots.cheer` 컬럼).
