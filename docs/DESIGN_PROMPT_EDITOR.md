# 테마 에디터 디자인 프롬프트

이 문서엔 **두 개**의 프롬프트가 있다. 각 `---` 블록을 통째로 claude.ai 에 붙여넣으면 그 화면 시안이 아티팩트로 생성된다.

1. **테마 에디터 홈** — 로그인 + 슬롯 목록/대시보드(만들기·고치기·지우기)
2. **서비스별 설정 화면** — 슬롯 하나를 편집할 때 서비스(타로/럭키드로우/롤링페이퍼)에 따라 달라지는 설정 폼

**공통 의도 (중요)**
- **레이아웃·구성·컨트롤 종류만** 뽑는다. 색·폰트·radius 같은 토큰은 정하지 않는다(중립 플레이스홀더). 이 도구는 이벤트 테마를 입지 않는 **고정 라이트**다 — 어떤 슬롯을 열든 같은 도구처럼 보인다.
- 아이콘은 **Lucide 인라인 SVG**만, 이모지 금지. 이미지 자리는 회색 플레이스홀더. 정지 시안(호버 정도).

## 프롬프트 1 — 테마 에디터 홈

너는 데스크톱 웹 관리도구 UI 디자이너다. 아이돌 생일카페 이벤트 페이지를 **슬롯 단위로 파는 플랫폼**의 최고관리자용 **슬롯 편집기 홈** 시안을 만들어라. 여기서 소유자가 이벤트 슬롯을 만들고, 목록에서 골라 편집하러 들어간다.

### 산출물
- **단일 HTML 아티팩트**, 인라인 CSS만, 외부 리소스 금지. 데스크톱 폭 기준(좁은 화면 대응도 보여주면 좋다).
- 아래 **두 상태**를 보여줘라: ① 로그인 화면 ② 로그인 후 슬롯 목록(대시보드).

### 화면
**① 로그인**
- 가운데 모인 좁은 카드. 서비스명("OLUCKY!")과 부제("최고관리자 · 슬롯 편집기"). 이메일·비밀번호 입력 + 로그인 버튼. 도구다운 담백한 라이트.

**② 슬롯 목록 (대시보드)**
- 상단 헤더: 제목 "슬롯" + 한 줄 안내("만들거나 고치면 바로 반영돼요 — 방문자가 그 주소로 들어올 수 있습니다."). 오른쪽에 보조 동작(불러오기·내보내기).
- **"새 슬롯" 만들기 섹션**(이 화면의 주인공): 슬러그(URL, 예: `seventeen-dino`) · 행사명(예: `세븐틴 디노 생일카페`) · 플랜 선택 · 기간 → **만들기** 버튼. 만들면 바로 편집 화면으로 들어간다.
- **슬롯 목록**: 카드/줄 형태로 기존 슬롯들. 각 항목에 행사명 + `/슬러그` + **서비스 배지(타로/럭키드로우/롤링페이퍼)** + 기간 상태(테스트/대여/종료) + [편집] [삭제]. 삭제는 위험 동작으로 구분.
- 빈 상태(슬롯 없음)도 살짝 보여주면 좋다.

### 마지막 체크
- "새 슬롯 만들기"가 이 화면의 주인공으로 도드라지는가?
- 목록 항목에 서비스 배지·슬러그·기간 상태가 한눈에 들어오는가?
- 로그인·목록 모두 **고정 라이트 도구** 인상인가?
- Lucide 인라인 SVG만, 이모지 없는가?

## 프롬프트 2 — 서비스별 설정 화면

너는 데스크톱 웹 관리도구 UI 디자이너다. 슬롯 편집기에서 소유자가 슬롯 하나를 편집하는 화면을 만들어라. 상단에서 **서비스(타로 / 럭키드로우 / 롤링페이퍼)** 를 고르면 아래 설정 항목이 그 서비스 것으로 바뀐다.

### 산출물
- **단일 HTML 아티팩트**, 인라인 CSS만, 외부 리소스 금지.
- 서비스 **셋의 설정 폼을 각각** 보여줘라(세로로 나열하거나 탭). 왼쪽이 설정 폼, 오른쪽에 **실시간 미리보기 자리(플레이스홀더 프레임)** 두는 2단.
- 폼은 **카드형 섹션 + 2열 그리드**로 촘촘히.

### 컨트롤 종류 (재사용)
색 = 견본+값칸, 이미지 = 업로드칸(썸네일+파일선택), 팔레트 = 정사각 견본 여러 개+추가/삭제, 토글 = 체크박스, 선택 = 드롭다운/세그먼트, 수치 = 슬라이더/숫자칸, 목록 = 행 추가/삭제.

### 공통 설정 (서비스 무관, 맨 위)
- **기본**: 서비스 선택(세 서비스 세그먼트), 슬러그, 행사명.
- **기간**: 테스트·대여 기간.
- **테마 색 / 형태**: 역할별 색 그룹, radius 슬라이더.
- **웹앱 아이콘**: "홈 화면에 추가" 용 정사각 아이콘 업로드.
- **주최자 · 저장하기**(상단·하단, 저장 전이면 "저장 안 됨" 표시).

### 서비스별 설정 패널 (핵심 — 서비스 고르면 이 부분이 바뀐다)

**A. 타로**
- 로고 · 배경 이미지 업로드.
- 카드 뒷면: 내장 문양 색 2개(그라디언트) — 뒷면 이미지 없을 때.
- 카드 앞면 78장: 대량 업로드 그리드(덱별 메이저·완드·컵·소드·펜타클), 채운/빈 칸이 한눈에.
- 수정구슬 이미지(리딩 로더용) 업로드.
- AI 리딩 플랜 / 한도: 플랜 선택 + 사용량 표시.
- 카테고리별 뽑기: 카테고리마다 뽑는 장수 등 설정 목록.
- (질문 타로의 질문·답변은 주최자가 따로 관리 — 여기 없음 안내 한 줄.)

**B. 럭키드로우**
- 상품·수량: 등수별 행 목록(등수·상품명·수량·배송 필요 토글) + 행 추가.
- 커버 연출: 스크래치 커버 문구/문양, 하이라이트(덮을) 등수 지정.
- 박스: 상단 여백·안쪽 여백·그림자(색·번짐·내림)·테두리(두께·색) 수치.
- 배송·경품 모달 색: 배경·글자·요소 배경·테두리색 + **"테두리 없음" 토글**.
- 수량 카운터 색: 배경·테두리·그림자색.
- 등수 배지 스타일: 옅게(soft) / 채움(solid).
- 폰트 드롭다운, 배경 이미지 업로드.
- (리허설·마감·표시 모드는 주최자 콘솔 — 여기 없음 안내 한 줄.)

**C. 롤링페이퍼**
- 문구: 벽 제목(+ **보이기 토글**), 벽 부제(+ **보이기 토글**), 입력 안내, 남기기 버튼 문구.
- 기본 글꼴 드롭다운(제목·UI용; 쪽지 글씨체는 방문자가 고른다는 안내).
- 색: 글자색·서브 글자색·포스트잇 본문색·이름색·벽 배경색·버튼색.
- 포스트잇 종이색 **팔레트**: 정사각 견본 여러 개 + 추가/삭제(방문자가 이 중 고른다).
- 이미지: 로고 · 벽 배경 · 스티커 세트(정사각 썸네일 + 아래 전체폭 "스티커 추가").

### 마지막 체크
- 서비스를 바꾸면 **아래 설정이 통째로 그 서비스 것**으로 바뀌는 구조가 드러나는가?
- 각 서비스 항목이 **카드형 섹션 + 2열**로 정리돼 위계가 읽히는가?
- 색·이미지·팔레트·토글·드롭다운 등 **컨트롤이 항목 성격에 맞게** 쓰였는가?
- 왼쪽 폼 + 오른쪽 고정 미리보기 2단인가? 고정 라이트 인상인가?
- Lucide 인라인 SVG만, 이모지 없는가?
