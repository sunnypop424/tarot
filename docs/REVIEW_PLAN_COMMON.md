## 규칙 절 (문서의 진짜 산출물, 각 5줄 이내)

1. **클래스 명명** — 방문자 화면은 CSS 모듈, 주최자는 `ad-*`, 편집기는 `admin.css`.
   모듈에서 `.card`/`.head`/`.empty` 를 새로 정의하기 전에 `components.css` 에 있는지 본다.
2. **공통 컴포넌트 사용** — 버튼·아이콘버튼·표면·칩·빈 상태는 전역 클래스를 `composes` 로
   끌어온다. 새 치수를 화면에서 만들지 않는다. `<img>` 는 `SavableImage` 하나.
3. **토큰** — hex·radius·shadow 리터럴 금지. `9999px` 는 `var(--radius-full)`.
   서비스 로컬 변수를 만들 땐 `--<svc>-*` 접두사와 그 이유 한 줄을 파일 머리말에.
4. **용어** — 화면은 손님, 코드는 방문자. 운영 주체는 주최자/최고관리자/스태프.
   종료는 "마감"(서비스) / "종료"(슬롯). 노출어는 "선물", "보상"은 코드에만.
5. **어투** — 전 화면 해요체. 확인창은 `~할까요?` + 짧은 동사 okLabel + 감정어 없는
   사실 진술 desc. 마감된 기능은 **왜 안 되는지 반드시 말한다**(조용한 disabled 금지).

- **코드 수정 없음.** 문자열 한 줄도 안 고친다 (적용은 문서 승인 뒤 별도 턴).
- 전면 리팩터 제안 없음 — 각 항목은 서비스 하나씩 순차 적용 가능한 단위로 쪼갠다.
- 프롬프트에 이미 적힌 수치를 다시 세지 않는다 (검증만 하고 넘어감).
