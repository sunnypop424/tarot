# 대표화면(홈) 디자인 프롬프트

Claude(claude.ai)에 아래 `---` 사이 내용을 그대로 붙여넣으면 홈 대표화면 시안이 아티팩트로 생성됩니다.
시안 확인 후 마음에 드는 방향이 나오면 그 결과를 구현 단계의 레퍼런스로 사용합니다.

**사용 팁**
- 한 번에 완성되지 않으면 "카테고리 타일을 더 크게", "카드 부채꼴을 더 넓게" 같은 후속 요청으로 다듬으세요.
- 다른 화면(결과 화면, 카드 뽑기 화면)이 필요하면 아래 §화면 사양 부분만 교체해서 재사용하세요.

---

너는 모바일 웹 UI 디자이너다. **타로카드 모바일 웹 "타로 포켓"의 홈 대표화면** 시안을 만들어라.

## 산출물

- **단일 HTML 아티팩트** 하나. 인라인 CSS만 사용하고 외부 리소스(CDN, 폰트, 이미지)를 절대 불러오지 마라 — 아티팩트에서 차단된다.
- 화면 폭 **390px 모바일 프레임**을 페이지 중앙에 세로로 배치하고, 프레임 바깥은 어두운 중립 배경으로 채워라.
- 실제 동작하는 앱이 아니라 **정지 시안**이다. 다만 hover/active 스타일 정도는 CSS로 표현해도 좋다.
- 카드 일러스트는 넣지 마라. 카드는 **뒷면(문양이 있는 패턴)** 상태로만 등장한다.

## 서비스 개요

회원가입도 서버도 없이 바로 쓰는 초경량 타로 웹. 카드를 뽑아 오늘의 조언을 얻는 30초짜리 리추얼.
분위기는 "점집의 어둑한 신비"가 아니라 **밤에 켠 무드등 아래의 조용한 리추얼** — 무겁지 않고, 무섭지 않고, 매일 열어보고 싶은 감도.

## 디자인 토큰 (반드시 이 값을 사용)

**색상 (다크 우선)**
- 캔버스 배경: `#0F1020`
- 표면(카드/타일): `#1A1B2E`
- 떠 있는 표면: `#242537`
- 브랜드 보라(주요 CTA·활성 상태): `#816BFF`
- 보라 hover: `#6E58FF`
- 연한 보라(보조 버튼 텍스트, 칩 텍스트): `#B7AAFF`
- 보라 워시(보조 버튼 배경, 칩 배경): `#241F45`
- 골드(카드 테두리·장식 아이콘·강조): `#D4AF37`
- 기본 텍스트: `#F2F0FA`
- 보조 텍스트: `#C6C3D8`
- 흐린 텍스트(메타): `#9A97B0`
- 구분선: `#2E2F45`

**색 역할 규칙 (중요)**
- 보라 = 인터랙션(CTA, 활성 탭, 선택 글로우). 골드 = 장식(카드 테두리, 아이콘, 강조 포인트).
- **골드를 버튼 배경처럼 넓은 면적에 쓰지 마라.** 포인트가 흔해지면 신비감이 죽는다.
- 빨강 계열은 쓰지 마라 (시스템 에러 전용).

**타이포그래피**
- `font-family: Pretendard, -apple-system, BlinkMacSystemFont, system-ui, "Noto Sans KR", sans-serif` — 웹폰트를 로드하지 말고 선언만 해라(폴백으로 렌더된다).
- 크기 스케일: 40 / 32 / 28 / 24 / 20 / 18 / 16 / 14 / 13 / 12px
- 웨이트는 세 단계만 — **400(본문·기본)과 600(제목·버튼·라벨)을 주로, 300(얇은거)은 특수한 경우만**. 700 이상 금지.
- 기본 행간 1.5, 해석 본문은 1.7.

**형태**
- 라운드: 버튼·토스트 8px, 카드·타일 16px, 칩·세그먼트 9999px
- 타로 카드 비율 **63:88 고정**(실물 타로 규격), 라운드는 **카드 폭의 9.4%**(170px 카드에서 16px — 작은 카드는 같이 줄어든다), 테두리 `1px solid #D4AF37`, 그림자 `0 4px 16px rgba(0,0,0,0.4)`
- 보라 글로우: `0 0 24px rgba(129,107,255,0.25)`
- 간격 단위 8px (컴포넌트 간 16~24px, 섹션 간 32~48px), 화면 좌우 패딩 20px
- 터치 타깃 최소 44px

**아이콘 (중요)**
- **Lucide 아이콘만 사용**하고, SVG를 인라인으로 직접 그려 넣어라 (외부 스크립트 로드 금지). stroke-width 1.5~2, 크기 20 또는 24px.
- **이모지 사용 절대 금지.** 아이콘이 필요한 모든 자리는 Lucide로.
- 카테고리 아이콘: 오늘의 타로 `sparkles` · 애정운 `heart` · 금전운 `coins` · 직업·학업운 `briefcase` · 예/아니오 `scale` · 이달의 조언 `moon-star`
- 장식·카테고리 아이콘은 골드(`#D4AF37`) stroke, 기능 아이콘(뒤로가기 등)은 텍스트 색 계열.

## 화면 사양 — 홈

위에서 아래로 이 순서:

1. **헤더** — 좌측에 서비스명 "타로 포켓", 우측에 Lucide `book-open` 아이콘 버튼(카드 도감 진입). 배경은 캔버스색, 하단에 1px `#2E2F45` 헤어라인.

2. **오늘의 카드 히어로** (가장 시각적 중심) — *아직 오늘 카드를 뽑지 않은 상태*로 그려라.
   - 중앙에 뒷면 카드 1장 (63:88 비율, 골드 테두리, 딥 네이비 바탕에 골드 별/달 문양 패턴을 SVG로 그려 넣어라). 살짝 떠 있는 느낌의 그림자.
   - 카드 아래 문구: "오늘의 카드가 당신을 기다리고 있어요" (18px/600)
   - 그 아래 오늘 날짜를 흐린 텍스트로 (예: "2026년 7월 15일 수요일", 13px)
   - 보라 primary 버튼 "오늘의 카드 뽑기" (높이 56px, 라운드 8px, 18px/600, 폭은 좌우 패딩 안 가득)
   - 배경에 은은한 별 장식(작은 점들, 불투명도 0.3 이하)을 깔아도 좋다. 과하지 않게.

3. **카테고리 그리드** — 섹션 제목 "무엇이 궁금한가요?" (20px/600). 그 아래 **2열 그리드로 타일 6개**.
   - 타일: 배경 `#1A1B2E`, 라운드 16px, 테두리 1px `#2E2F45`, 패딩 20px 16px
   - 타일 내부: 골드 Lucide 아이콘(24px) → 카테고리명(18px/600) → 한 줄 설명(13px, 흐린 텍스트)
   - 6개 항목과 설명:
     - 오늘의 타로 — "하루 한 장의 메시지"
     - 애정운 — "그 사람의 마음이 궁금할 때"
     - 금전운 — "돈의 흐름 살펴보기"
     - 직업·학업운 — "지금 이 길이 맞을까"
     - 예 / 아니오 — "가장 단순한 답"
     - 이달의 조언 — "이번 달의 키워드"
   - 첫 번째 타일 하나만 **선택/활성 상태**로 표현해라: 테두리 `#816BFF` + 보라 글로우.

4. **질문 타로 섹션** — 섹션 제목 "질문 타로" (20px/600) + 우측에 "전체보기" (13px, 흐린 텍스트).
   - 질문 3개를 세로 리스트로. 각 행: 배경 `#1A1B2E`, 라운드 16px, 패딩 16px, 질문 텍스트(16px/400) + 우측 Lucide `chevron-right`.
   - 질문 예시: "지금 이직해도 괜찮을까요?" / "그 사람과 다시 만날 수 있을까요?" / "올해 안에 목돈을 모을 수 있을까요?"

5. **하단 탭바** — 화면 하단 고정. 배경 `#1A1B2E`, 상단 1px `#2E2F45` 헤어라인, 높이 64px.
   - 3개 탭 (Lucide 아이콘 24px + 12px 라벨): 홈 `house` / 운세 `calendar-days` / 도감 `layout-grid`
   - **홈 탭이 활성**: 아이콘·라벨 `#816BFF`. 비활성 탭은 `#9A97B0`.

## 톤 & 카피 규칙

- 존댓말 해요체. 곁에서 카드를 읽어주는 다정한 조언자의 어조.
- 단정적 예언("반드시 ~합니다") 금지. 위압적이거나 무서운 표현 금지.
- 화면 최하단(탭바 위)에 아주 작은 면책 문구를 12px 흐린 텍스트로: "타로는 재미와 성찰을 위한 것이에요."

## 마지막 체크

제출 전 스스로 확인해라:
- 이모지가 하나도 없는가? 모든 아이콘이 인라인 Lucide SVG인가?
- 골드가 장식에만 쓰였고, 넓은 면적을 차지하지 않는가?
- 폰트 웨이트가 400·600(·특수한 경우 300)만 쓰였는가?
- 카드가 63:88 비율에 골드 테두리인가?
- 390px 폭에서 좌우 스크롤 없이 모든 요소가 들어가는가?
