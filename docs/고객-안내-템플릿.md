# 주최자 안내 메시지 — 템플릿

제작이 끝난 뒤 **주최자(고객)에게 그대로 보내는** 안내다.
톤은 "설정은 우리가 다 해뒀고, 당신은 질문·답변만 채우면 된다" 이다 — 테마·이미지·플랜은 주최자의 몫이 아니다 (역할 분리).

> **이 문구는 이제 편집기가 자동으로 만들어 준다.** 슬롯 편집기 하단 ‘주최자 계정’ 패널에서
> 계정을 만들거나 비밀번호를 재발급하면, 그 슬롯 값(주소·계정·기간)이 채워진 안내문이 바로 아래에 뜨고
> **‘안내문 복사’ 버튼**으로 복사해 전달만 하면 된다 (`src/owner/guide.ts`).
> 이 파일은 그 문안의 **원본**이다 — 화면 문구를 바꾸려면 `guide.ts` 와 이 파일을 **같이** 고친다
> (한쪽만 고치면 어긋난다). 손으로 채워 보내야 할 때만 아래 `${...}` 자리를 직접 채운다.

---

## 채울 값

| 자리 | 예시 | 어디서 |
|---|---|---|
| `${eventName}` | 스타릿 리안 생일카페 | 슬롯 이벤트명 |
| `${slug}` | `starlit-rian` | 슬롯 슬러그 |
| `${siteUrl}` | `https://tarot-btjp.vercel.app/starlit-rian` | 배포 주소 + 슬러그 |
| `${adminUrl}` | `https://tarot-btjp.vercel.app/starlit-rian/admin` | 위 + `/admin` |
| `${email}` | `rian@example.com` | 편집기에서 만든 주최자 계정 |
| `${password}` | (직접 정한 비밀번호) | 계정 만들 때 정한 값 |
| `${testPeriod}` | 7/1 ~ 7/3 | 슬롯 테스트 기간 |
| `${rentPeriod}` | 7/4 ~ 7/6 | 슬롯 대여 기간 |

## 보낼 문구 (여기부터 복사)

**${eventName} 타로 이벤트 안내**

방문자용 주소 (링크로 공유하거나 QR 로 만들어 카페에 두세요)
${siteUrl}

관리자 로그인
${adminUrl}

관리자 아이디 / 비밀번호
${email} / ${password}

---

**1) 방문자는 이렇게 씁니다**

방문자가 위 링크를 열면(또는 카페에 두신 QR 을 찍으면) 바로 타로 화면이 열립니다.
**회원가입도 로그인도 없습니다** — 열고 바로 카드를 뽑습니다.
오늘의 카드·주간·월간, 그리고 질문 타로를 고를 수 있어요.

**2) 관리자가 하는 일 — 질문과 답변 관리**

관리자 주소로 들어가 로그인하시면 **질문 타로** 화면이 나옵니다.
여기서 하시는 건 두 가지뿐이에요 (색·이미지·이벤트 설정은 저희가 이미 맞춰뒀습니다):

- **질문 추가** — 방문자가 고를 질문을 적습니다. ("그 사람과 다시 만날 수 있을까요?" 처럼)
- **답변 입력** — 질문을 누르면 카드마다 보여줄 답변을 적는 화면이 나옵니다.
  직접 적으셔도 되고, **‘AI로 전체 생성’** 을 누르면 카드별 답변을 한 번에 만들어 드립니다.
  만들어진 답변은 **검수 화면에서 확인하고 저장**을 눌러야 방문자에게 나갑니다 (바로 반영되지 않아요).

각 질문 왼쪽의 **‘공개’ 체크박스**를 켜야 방문자 화면에 나옵니다.
체크를 끄면 방문자에게는 그 질문이 아예 보이지 않습니다 (준비 중인 질문을 숨겨둘 수 있어요).

> **질문·답변은 저장을 따로 누르지 않아도 바로 반영됩니다.** (저장을 잊어 날리는 것보다 낫게 만들었습니다.)

**3) 비밀번호는 꼭 바꿔주세요**

처음 받으신 비밀번호는 저희도 아는 값입니다.
관리자 화면 왼쪽 메뉴의 **‘내 계정’** 에서 본인만 아는 비밀번호로 바꿔주세요.

**4) 기간 안내**

- 테스트 기간: ${testPeriod} — 미리 열어보고 질문·답변을 채우실 수 있어요.
- 실제 운영(대여) 기간: ${rentPeriod} — 방문자가 들어올 수 있는 기간입니다.

**대여 기간이 지나면 주소가 닫힙니다.** 방문자는 물론 관리자도 들어갈 수 없게 되니,
연장이 필요하시면 미리 말씀해 주세요.

---

**미리 확인 부탁드립니다**

- 방문자에게는 위 방문자용 주소를 링크로 보내거나 QR 로 만들어 두시면 됩니다.
- 행사 전날, 실제로 쓰실 기기(태블릿·휴대폰)로 주소를 한 번 열어 확인해 주세요.
- 질문·답변 입력은 **테스트 기간에 미리** 끝내두시는 걸 권합니다.

궁금한 점은 언제든 편하게 연락 주세요.

## 보내기 전 스스로 점검

- [ ] `${siteUrl}` 을 **다른 브라우저(로그인 안 된)** 로 열어 화면이 뜨는가
- [ ] 관리자 계정으로 `/admin` 로그인이 되는가 (틀린 비번은 막히는가)
- [ ] 테스트 기간이 **오늘을 포함**하는가 — 아니면 주최자가 열어도 안 열린다
- [ ] 카드 앞/뒷면·로고·배경 이미지가 다 올라갔는가 (빈 카드가 없는가)
- [ ] 플랜에 맞는 AI 한도가 들어갔는가 (`docs/PRICING.md`)
