# 제작 전 — 고객에게 받을 것

슬롯 하나를 만들기 전에 **주최자(고객)에게서 받아야 하는 것들**의 체크리스트다.
여기 있는 값이 그대로 슬롯 편집기(`/theme-editor`)의 입력이 된다 — 항목 순서도 편집기 패널 순서와 맞췄다.

받는 쪽(고객)에게 그대로 보내도 되도록 **질문 형태**로 적었다. `docs/고객-안내-템플릿.md` 는 이걸 다 받아 만든 뒤 **돌려보내는** 안내다.

---

## 1. 기본 정보

- **이벤트명** — 예: "스타릿 리안 생일카페". 로고 이미지를 안 주시면 이 이름이 로고 자리에 나옵니다.
- **원하시는 주소(슬러그)** — 예: `starlit-rian`. 영문 소문자·숫자·하이픈만. 정해주시면 `사이트/starlit-rian` 가 됩니다.
- **행사 날짜**
  - 테스트 기간 (미리 준비하실 기간): ____ ~ ____
  - 실제 운영(대여) 기간: ____ ~ ____
  - → **대여 기간이 지나면 주소가 자동으로 닫힙니다.**

## 2. 색 (테마)

- **대표 색 하나** (팬들이 아는 그 색) — HEX 코드나 이미지로. 예: `#816BFF`
  - 이 색을 기준으로 나머지 색은 저희가 맞춥니다. 원하시면 밝은 톤/어두운 톤도 골라주세요.
- 특별히 원하시는 분위기(다크/라이트, 파스텔/쨍한 등)가 있으면 알려주세요.

## 3. 이미지 — **전부 선택**, 안 주시면 기본값으로

> 이미지는 전부 **저희가 올립니다** (주최자 화면에서는 못 올립니다 — 테마의 일부라서요).
> 파일로 주시면 됩니다. **형식: PNG · JPG · WEBP · GIF · SVG · 파일당 최대 5MB.**
> (5MB 를 넘으면 카페 모바일에서 안 뜹니다. 카드처럼 여러 장이면 WEBP 를 권합니다.)

카드·수정구슬·로고는 **비율이 중요합니다.** 아래 비율과 다르면 화면에서 잘리거나 작게 나옵니다.

| 이미지 | 비율 / 크기 | 왜 |
|---|---|---|
| **카드 앞면** | **세로 63 : 88** (타로 카드 표준 비율) | 이 비율로 화면을 꽉 채웁니다(`cover`) — 다르면 **위아래나 좌우가 잘립니다.** |
| **카드 뒷면** | **세로 63 : 88** (앞면과 같게) | 앞면과 같은 카드 틀에 들어갑니다. 역시 다르면 잘려요. |
| **수정구슬** | **정사각형 1:1** | 96px 로 보이지만 고해상도 화면 대비 **최소 300×300 이상**을 권합니다. |
| **로고** | **가로로 긴 형태**, 배경 **투명 PNG** | 높이는 저희가 맞춥니다(기본 28px). 세로로 긴 로고는 너무 작아져요. |
| 배경 무늬 | **상관없음** | 은은하게 깔리는 패턴이라 어떤 크기든 됩니다. |

- **카드 앞면** — 타로 카드 그림.
  - **전체 78장** 또는 **메이저 22장** 중 무엇으로 하실지.
  - 파일명 규칙은 저희가 맞추니, 어떤 카드인지 구분만 되게 주시면 됩니다.
  - **권장 픽셀 크기: 세로 약 630×880 이상** (63:88 을 지키면서). 너무 작으면 카드가 흐려집니다.
- **카드 뒷면** — 뽑기 전 카드 그림. (없으면 내장 별무늬)
- **수정구슬** — AI 리딩을 기다릴 때 뜨는 그림. (없으면 내장 그림)
- **로고** — 상단에 들어갑니다. (없으면 이벤트명 글자)
- **배경 무늬** — 은은하게 깔리는 패턴. (없으면 단색 배경)

> **카드 앞·뒷면 요약:** 세로가 긴 **63:88** (일반 카드 모양). 이 비율만 지키면 잘리지 않습니다.
> 수정구슬은 **정사각형**, 로고는 **가로로 길고 배경 투명**.

## 4. 질문 타로 — 질문과 답변

- **질문 목록** — 손님이 고를 질문들. 예: "그 사람과 다시 만날 수 있을까요?"
- **답변을 어떻게 채울지**
  - (a) 주최자가 **직접** 입력 — 카드마다 답변을 적으십니다.
  - (b) **AI 생성** — 버튼 한 번으로 카드별 답변을 만들고, 검수 후 저장.
  - → (b) 는 플랜에 따라 **생성 횟수 한도**가 있습니다 (아래).

## 5. 플랜 (AI 예산)

AI 를 얼마나 쓰실지에 따라 플랜을 정합니다. 상세 가격은 `docs/PRICING.md`.

- **무료** — AI 없음. 카드별 개별 해석만.
- **라이트 / 스탠다드 / 프리미엄** — AI 리딩(3장 종합)·답변 생성 한도가 커집니다.
- 3장 스프레드(카드를 이어 읽는 AI 종합)는 **스탠다드부터**입니다.
- 추가 결제로 한도를 더 드릴 수 있습니다.

## 6. 관리자 계정

- **관리자 이메일** — 주최자가 로그인할 주소. 예: `rian@example.com`
  - 실제 쓰시는 메일이 아니어도 됩니다 (로그인 아이디로만 씁니다).
  - 비밀번호는 저희가 정해 전달하고, 주최자가 첫 로그인 후 바꿉니다.

---

## 우리 쪽 준비 순서 (받은 뒤)

1. `/theme-editor` 로그인 → **슬롯 만들기** (슬러그·이벤트명·플랜·기간 입력)
2. 편집기에서 색·이미지·카드 앞면 올리기 → **저장하기** (= 배포)
3. **주최자 계정 만들기** (편집기 하단 ‘주최자 계정’ 패널, 이메일·비밀번호)
4. 대비 검사 통과 확인 → 미리보기로 실제 화면 확인
5. `docs/고객-안내-템플릿.md` 채워서 주최자에게 전달

> **최고관리자 계정은 SQL 로만 만듭니다** (편집기에 그 기능은 없습니다) — `docs/BACKEND.md §1-3`.
> 새 함수 배포·마이그레이션이 필요하면 같은 문서를 봅니다.
